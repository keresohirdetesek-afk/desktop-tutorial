# Hirdetési képek

Ide kerülnek az eladott hirdetések képei. A `js/hirdetes.js` innen
hivatkozik rájuk.

A képnek **a saját kiszolgálónkon** kell lennie: külső címről betöltött
kép a hirdető felé elárulná a látogató IP-címét, és a kód ezért ki is
hagyja az ilyen bejegyzést.

A beállítás menete a `HIRDETES.md` 1. pontjában.
